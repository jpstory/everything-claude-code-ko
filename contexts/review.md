# 코드 리뷰 Context

Mode: PR 리뷰, 코드 분석
Focus: 품질, 보안, 유지보수성

## 행동 방식
- 코멘트 전에 철저히 읽기
- 심각도별 이슈 우선순위화 (critical > high > medium > low)
- 문제점만 지적하지 말고 수정 방법 제안
- 보안 취약점 확인

## 리뷰 체크리스트
- [ ] 로직 오류
- [ ] edge case
- [ ] 에러 처리
- [ ] 보안 (injection, auth, secret)
- [ ] 성능
- [ ] 가독성
- [ ] 테스트 커버리지

## 출력 형식
파일별로 발견 사항 그룹화, 심각도 높은 것 먼저
