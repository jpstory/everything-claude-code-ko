# /learn - 재사용 가능한 패턴 추출

현재 세션을 분석하여 skill로 저장할 가치가 있는 패턴을 추출합니다.

## 트리거

세션 중 사소하지 않은 문제를 해결했을 때 언제든지 `/learn` 실행.

## 추출 대상

다음을 찾아보세요:

1. **에러 해결 패턴**
   - 어떤 에러가 발생했는가?
   - 근본 원인이 무엇이었는가?
   - 무엇이 해결했는가?
   - 유사한 에러에 재사용 가능한가?

2. **디버깅 기법**
   - 명확하지 않은 디버깅 단계
   - 효과가 있었던 tool 조합
   - 진단 패턴

3. **우회 방법**
   - 라이브러리 quirk
   - API 제한사항
   - 버전별 수정

4. **프로젝트 특화 패턴**
   - 발견한 codebase 규칙
   - 결정한 아키텍처
   - 통합 패턴

## 출력 형식

`~/.claude/skills/learned/[pattern-name].md`에 skill 파일 생성:

```markdown
# [설명적인 패턴 이름]

**추출일:** [날짜]
**Context:** [적용 시점에 대한 간단한 설명]

## 문제
[이 패턴이 해결하는 문제 - 구체적으로]

## 솔루션
[패턴/기법/우회 방법]

## 예시
[해당되는 경우 코드 예시]

## 사용 시점
[트리거 조건 - 이 skill을 활성화해야 하는 상황]
```

## 프로세스

1. 세션에서 추출 가능한 패턴 검토
2. 가장 가치 있고 재사용 가능한 인사이트 식별
3. skill 파일 초안 작성
4. 저장 전 사용자 확인 요청
5. `~/.claude/skills/learned/`에 저장

## 참고사항

- 사소한 수정은 추출하지 않기 (오타, 간단한 문법 오류)
- 일회성 이슈는 추출하지 않기 (특정 API 장애 등)
- 향후 세션에서 시간을 절약할 패턴에 집중
- skill은 집중적으로 유지 - skill당 하나의 패턴
