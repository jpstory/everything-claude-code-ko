# Build and Fix

TypeScript 및 빌드 오류를 점진적으로 수정:

1. 빌드 실행: npm run build 또는 pnpm build

2. 오류 출력 파싱:
   - 파일별로 그룹화
   - 심각도별로 정렬

3. 각 오류에 대해:
   - 오류 context 표시 (앞뒤 5줄)
   - 이슈 설명
   - 수정 제안
   - 수정 적용
   - 빌드 재실행
   - 오류 해결 확인

4. 중단 조건:
   - 수정이 새 오류를 도입할 때
   - 3회 시도 후에도 같은 오류가 지속될 때
   - 사용자가 일시 정지를 요청할 때

5. 요약 표시:
   - 수정된 오류
   - 남은 오류
   - 도입된 새 오류

안전을 위해 한 번에 하나의 오류만 수정!
